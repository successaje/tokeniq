# 🧠 TokenIQ: Autonomous CFO for Onchain Capital

**TokenIQ** is an **Arbitrum-native** AI Treasury Agent that empowers businesses, DAOs, and funds with smart treasury management and yield optimization strategies. 

> Think: **Quant-as-a-Service** + **Decentralized BlackRock**  
> Powered by **AI-driven capital allocation**, TokenIQ turns idle capital into intelligent yield on Arbitrum.

## 🚀 Key Features

### ✅ AI Treasury Manager
- Smart, risk-adjusted allocation of idle capital.
- Automated rebalancing based on yield performance and protocol health.
- Structured AI outputs determining Decision, Reasoning, Risk Level, and Expected Yield.

### ✅ Arbitrum-Native Vaults
- ERC-4626 standard vaults customized for Arbitrum's high-performance DeFi ecosystem.
- Seamless integrations with leading Arbitrum DEXs and money markets.

### ✅ Institutional Dashboard
- Clean, professional interface built for treasury managers.
- Track performance, view AI-driven recommendations, and execute strategies.
- Non-custodial and fully transparent.

## 🚀 Local Development

### Prerequisites
- Node.js 18+
- npm or pnpm

### Setup

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Visit `http://localhost:3000` to view the application.
