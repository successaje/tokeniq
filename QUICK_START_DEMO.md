# TokenIQ Quick Start Demo Guide

## 🚀 5-Minute Quick Demo

### Essential Flow (Show These 3 Things):

1. **Discover Page → Activate TokenIQ Intelligence** (2 min)
   - Expand "AI-Powered Capital Optimization"
   - Click "Activate TokenIQ Intelligence"
   - Show wallet popup → Confirm
   - Watch allocation animation
   - **Say**: "This is real-time AI optimization on Sei Network"

2. **Portfolio → Emergency Withdraw** (1.5 min)
   - Click "Emergency Withdraw" on any strategy
   - Show wallet confirmation
   - Show instant state change
   - **Say**: "Sei's fast finality enables instant withdrawals"

3. **Insights → Explain Reasoning** (1.5 min)
   - Click "Explain Reasoning"
   - Show AI-generated insights (if Ollama running)
   - Show detailed metrics
   - **Say**: "AI-powered analysis using Sei Intelligence Layer"
